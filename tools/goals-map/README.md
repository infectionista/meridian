# Science Map 11–14 — генератор

Страница `goals-map-11-14.html` в корне репозитория собирается этим скриптом, руками её не редактировать.

## Как перегенерировать

Нужен Python 3 с `openpyxl` (`pip install openpyxl`).

```
cd tools/goals-map
python3 build.py
```

Скрипт читает цели из `Learning_goals_11-14_classroom_v2.xlsx` (лист «Learning goals»), подставляет данные в `template.html` и перезаписывает `goals-map-11-14.html` в корне репо. Дальше — обычный commit + push, Vercel подхватит сам.

## Что где менять

- **Цели (узлы)** — строки в xlsx. У каждой новой цели код вида `U<юнит>.<K|A|C><номер>`; короткий ярлык для узла добавить в словарь `LABELS` в `build.py`.
- **Рёбра** — список `edges` в `build.py`: `E('U1.K1','U1.A1','unit'|'cross','почему связаны')`. `unit` — сплошное ребро внутри юнита, `cross` — пунктирный мост между юнитами.
- **Вложить тренажёр или ридинг** — параметр `links` у узла (словарь `NODE_LINKS`) или у ребра (последний аргумент `E(...)`): `[{'t':'Название','u':'https://…','k':'trainer'|'reading'}]`. На карте появится нажимаемая кнопка ⚡.
- **Цвета и расположение кластеров** — словарь `UNITS` (`ax`/`ay` — якорь кластера на холсте 1600×1000).
- **Оформление и поведение страницы** — `template.html` (плейсхолдер `__DATA__` заменяется скриптом).

Скрипт валидирует данные сам: падает на ребре с несуществующим кодом, дубликате ребра и предупреждает об изолированных узлах.
